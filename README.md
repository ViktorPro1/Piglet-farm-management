# П'ятачок — Управління свинофермою

React + TypeScript + Vite додаток для ведення обліку на свинофермі.

## Live Demo

https://piglet-farm-management.vercel.app

## Функціонал

- Облік поголів'я — список тварин з фільтрами, додавання та редагування
- Породи свиней — каталог з характеристиками та описами
- Калькулятор корму — розрахунок раціону та витрат за типом тварини
- Опороси — календар з автоматичним розрахунком дати (+114 днів)
- Вакцинація та обробки — облік щеплень з нагадуваннями
- Довідник хвороб — симптоми, лікування та профілактика

Всі дані зберігаються в `localStorage` без потреби у бекенді.

## Стек

- React 18
- TypeScript
- Vite 8
- React Router DOM
- PWA (vite-plugin-pwa)
- localStorage

## Запуск

```bash
npm install --legacy-peer-deps
npm run dev
```

## Збірка
